# 揽收车队改造：使用与验收

> 范围变更：用户最新要求为“只先优化聊天窗展示”。本轮最终交付和页面验收仅针对聊天窗口；变更前已写入的价格、Excel及审核相关工作区内容保留，不作为本轮完整交付承诺。下文这些部分仅保留为前期实现说明。

本期保留“企微信息分析助手”主标题，业务方向为“揽收车队群聊分析”。不实现空运分析、采集解密、OCR、附件深度解析或消息发送。

## 操作

1. 在页面选择账号、来源及群聊范围，点击“刷新当前范围”。“路线报价与时效”默认显示价格明细，无需打开业务轮次。
2. 七个主列为起点、终点、重量、体积、包装数量、时效、价格。缺项显示“待补充”，底层保持空值；“待完善”和“待审核”均不会替换有效价格。
3. 每行可查看明细、查看证据、导出此条 Excel。人工补全与纠正使用原有候选校验、审核及版本检查，需先配置本地审核负责人。
4. “导出当前筛选全部”沿用当前价格视图与公司、路线、关键词筛选，服务端读取完整匹配范围，不受已加载行数限制。填写模板及维护文件仍使用原有预览、逐行校验与审核流程。
5. 单条 Excel 是展示文件：主工作表仅七列表头与一条所选报价；说明页注明公司、状态、单位、业务方向及用途。它不能作为回传维护模板。

## 聊天证据

价格行和业务轮次统一打开只读聊天窗口。中技业务方位于右侧、浅绿气泡；人工确认的供应商位于左侧、白色气泡；其他身份中性显示“身份待确认”。身份不根据正文 @ 提及判断。转发按原作者显示。

供应商确认复用公司身份纠正入口，需明确公司、范围、核验依据和已配置审核员。角色确认单独保存在分析库，不修改原始消息。未经确认的非中技公司不会自动变成供应商。

打开时定位并高亮所选消息，关联询价、报价及相邻消息可同时阅读。引用可定位原消息，转发卡片可进入并返回；上下文按需扩大，单次目标两侧各最多 200 条。更远消息仍可在全量消息检索中打开。关闭或 Esc 恢复打开前的页面位置与焦点。

聊天窗口不展示来源详情、消息 ID、哈希、JSON、文件路径或关联算法；底层证据记录继续保留。未解析附件只显示简短提示，不补造正文。所有读取和下载沿用脱敏与范围隔离。

## 运行边界

实施在原 `main` 工作区上完成，保留先前未提交内容，不创建分支、提交、推送或部署。新验收实例只使用临时 SQLite 和明确标记的合成数据，原运行进程和真实数据库不切换、不重建。

项目生产入口仍为：

```powershell
.\.venv\Scripts\python.exe -m chatlog_assistant wecom-local serve --analysis-db <分析库路径> --host 127.0.0.1 --port <空闲端口>
```

页面 HTML 与 Python 代码在服务启动时加载；已启动的旧服务不会自动变成新版本。真实分析库若需回填新增候选，应先备份并明确范围后再执行原有 rebuild 流程。不要把合成验收数据库误认为真实业务数据。

## 实际验证记录

2026-09-03 使用临时分析数据库及合成群聊，在本地 8879 端口打开真实页面，验证价格和业务轮次入口均打开同一聊天窗口。中技方右侧浅绿色、已确认供应商左侧白色，未知身份明确标注；姓名和公司显示正确。点击引用定位原消息，展开转发显示原作者并可收起；上下文由 22 条扩展至 42 条；Esc 恢复原页面筛选与触发按钮焦点。390px 窄屏下聊天正文自然换行。

相关集成测试实际运行 65 项通过，其中聊天窗口的身份、范围、转发与上下文测试 3 项。未访问或改写企微原始库，未切换原 8878 服务，未调用外部模型。最终页面仍须重新加载以读取新的 HTML；生产服务需由使用者按现有流程重启才会加载新代码。

## 后续真实数据 UI 验证与最小兼容修复

用户随后要求将相同 UI 用于既有真实群聊。经授权，先备份分析库，再用独立的 8880 服务连接原分析库；保留原群名，业务线不替代群名。未重导消息或重建分析，启动后逐表对比消息、问题、回复和人工维护记录与备份一致。

真实页面发现旧消息虽有原作者公司及中技分类，新增的 `company_status` 却仍为默认 `unknown`，使新版聊天窗口全部显示中性气泡。最小修复只在聊天读取视图中恢复彼此一致且无冲突的历史中技身份；不更新数据库，不猜测供应商。回归测试先复现 `unknown != zhongji`，修复后聊天、价格和原生转发相关 25 项测试通过，包含旧数据不改写、原作者转发身份、公司冲突、缺失公司和正文 @ 不影响身份的边界。

已在真实页面点击对应物流询价确认：中技气泡在右侧、浅绿色；未确认供应商保持左侧中性样式。真实价格回填、供应商批量确认和完整价格业务验收未实施。真实截图、数据库备份及运行产物仅保存在本机，不纳入 Git。
